# PatchScope v2.0.0 Update

PatchScope has been updated to v2.0.0.

## Improvements

- Configurable rule priorities through an explicit JSON configuration file.
- Options to disable individual rules.
- Explained suppressions with required justifications.
- SARIF 2.1.0 export for code-scanning workflows.
- Markdown, JSON, and SARIF reports through the GitHub Action.
- Dependency checks that match manifests with compatible lockfiles in the same directory.
- Documentation covering configuration, suppressions, exports, and limitations.

PatchScope continues to run locally without API keys, accounts, or model calls.

Findings are heuristic review prompts and require human assessment.

## Documentation Scope

This file summarizes existing capabilities. It does not modify application code, dependencies, configuration, or runtime behavior.
